Support

Questions, bugs, and ideas.

Proxy Manager is a small open-source project. Support runs through GitHub Issues, where answers stay public so others can find them too.

Report a bug

Found something broken? Open an issue with the steps to reproduce it and your macOS version. Include the relevant log lines if you can:

log stream --predicate 'subsystem == "com.proxymanager.app"' --level debug

Request a feature

If there is something you wish the app did, open an issue and describe the use case — or send a pull request.

Common questions

macOS won’t open the app. Proxy Manager isn’t notarized by Apple, so macOS may block the first launch. Open System Settings → Privacy & Security and click Open Anyway for Proxy Manager. You only need to do this once; the app updates itself normally afterwards.

How do updates work? The app checks for new versions via Sparkle in the background and always asks before installing. You can change the frequency or turn checks off in Settings → General. Release notes live on the Releases page.

Is my data private? Yes. There is no telemetry and no analytics; TLS is passed through untouched and metadata stays on your machine. See the privacy policy.

Do I need my own tunnel? Proxy Manager routes to a SOCKS5 proxy that you provide — for example ssh -D 1080 user@host. Or switch on “Run the tunnel for me” and let the app create and supervise the SSH tunnel for you. See the FAQ for more.

Can I route traffic per app? Yes. In Settings → Apps, each app can be set to Tunnel all, Use target rules (follow the host allow-list), or Direct all, with a default for apps you don’t list. You can also set the frontmost app’s mode from the menu bar. It’s off until you turn it on.
