Everything it does

A focused tool: route an allow-list, watch it work, and never break the rest of your connection.

  • Allow-list routing

    Only the hostnames you list go through the tunnel. No match means direct — the local proxy is a policy router, not a MITM.

  • Works for every app

    Sets the macOS system proxy for browsers and apps, and injects HTTP_PROXY/HTTPS_PROXY for CLI tools that can’t speak SOCKS5 directly.

  • Bring your own tunnel

    Use any SOCKS5 proxy you already run, or have the app run and supervise ssh -N -D for you, with key-file or password auth.

  • Live monitoring

    A live feed of route decisions, hosts, methods, bytes, latency, and status — plus request-rate charts and per-host breakdowns.

  • Never breaks your internet

    A tiny crash watchdog restores your original proxy settings within milliseconds if the app is force-quit or crashes, so your connection is never left pointing at a dead local port.

  • No MITM, no certificates

    TLS passes through untouched. The app records metadata only and stores it locally in SQLite — no request bodies, no headers, no cloud.

  • Presets and wildcards

    Start from curated allow-lists for common services, then add exact hosts or *.example.com wildcards of your own.

  • Self-updating

    Sparkle 2 checks for new versions in the background and always asks before installing. Update checks are Never / Daily / Weekly.

  • Prompt-free toggling

    Proxy settings for your network services are per-user, so enabling and disabling routing needs no password prompt on a normal setup.

How it works

One local hop decides where each connection goes.

Apps & CLI browser · curl · node
→
Local proxy 127.0.0.1:8888
→
Allow-listed → SOCKS5 tunnel
Everything else → direct
  1. Turn it on. One switch in the menu bar or the dashboard starts the local proxy, applies the system proxy, and exports the shell environment.
  2. Traffic is classified. Each connection is matched against your allow-list and routed to the tunnel or straight out — streaming is passed through with backpressure, so long-lived responses aren’t buffered.
  3. Watch it work. Every request appears in the live feed with its decision, size, and timing. Turn it off and your original proxy settings are restored.

Private by design

  • No TLS interception. The app never sees plaintext — CONNECT streams are relayed byte-for-byte.
  • Local-only. The proxy binds to 127.0.0.1. A non-loopback client is blocked from loopback, link-local, and private destinations.
  • Metadata only, on your disk. Host, size, timing, and status are stored in a local SQLite file; request bodies and headers are never recorded.
  • Secrets stay in the Keychain. An SSH password is fed to ssh through a one-shot askpass helper — never in the config file or on a command line.
  • Open source. MIT licensed; read every line on GitHub.
