Run the tunnel for me

No tunnel yet? Let the app run one.

Already have a SOCKS5 proxy? Point at it. Don’t? Give Proxy Manager your SSH host and it runs and supervises the tunnel for you — restarting it automatically if the connection drops.

  • Key-file or password auth; the password is stored in the Keychain, never in the config.
  • Automatic restart with backoff, and a one-click Restart tunnel.
  • Auth, host-key, and key-file errors are surfaced instead of retried forever.

How it works

One local hop decides where each connection goes.

Apps & CLI browser · curl · node
→
Local proxy 127.0.0.1:8888
→
Allow-listed → SOCKS5 tunnel
Everything else → direct
  1. Turn it on. One switch starts the proxy and wires it into macOS and your shell.
  2. Traffic is classified. Each connection is routed to the tunnel or straight out, streamed with backpressure.
  3. Watch it work. Every request shows up live. Turning it off restores your original settings.

Private by design

  • No TLS interception. CONNECT streams are relayed byte-for-byte.
  • Local-only. Binds to 127.0.0.1; private destinations are blocked for non-loopback clients.
  • Metadata only, on disk. Host, size, timing, and status in a local SQLite file. No bodies or headers.
  • Secrets in the Keychain. An SSH password is never written to the config or a command line.

Questions

Do I need my own server or tunnel?

Yes — Proxy Manager routes to a SOCKS5 proxy that you provide. Make one with ssh -D 1080 user@host, or switch on “Run the tunnel for me” and let the app create and supervise the SSH tunnel.

What is a SOCKS5 proxy?

A lower-level pipe that carries traffic to a remote machine. Your apps speak HTTP to the local proxy; the local proxy speaks SOCKS5 to your tunnel, so CLI tools that can’t do SOCKS5 directly still work.

Does all my traffic go through the tunnel?

No. Only the hostnames on your allow-list. Everything else connects directly, so the rest of your browsing is unaffected.

Will it work with curl, node, and other CLI tools?

Yes. It writes HTTP_PROXY/HTTPS_PROXY into your shell rc files, so new terminal sessions route through it automatically.

Is this a VPN?

No. It’s an allow-list HTTP proxy, not a system-wide tunnel or packet-level VPN. It never touches traffic that isn’t on your list.

What happens if the app crashes while routing is on?

A tiny crash watchdog restores your original proxy settings within milliseconds, so your internet is never left pointing at a dead local port.

Can the app see my traffic?

No. TLS is passed through untouched; only metadata (host, size, timing, status) is recorded, and only on your disk.

Route what you choose. Leave the rest alone.
