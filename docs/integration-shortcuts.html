The intents only run while Allow external control and Shortcuts and Siri are on in Settings → Integration.

Intents

IntentWhat it does
Set Proxy Manager Routingturns routing on or off
Toggle Proxy Manager Routingflips it and reports the new state
Get Proxy Manager Statusreads the routing state and tunnel health
Add Proxy Manager Targetadds a host or wildcard, after confirmation
Remove Proxy Manager Targetremoves a host or wildcard
List Proxy Manager Targetsreturns the patterns and reads them aloud
Set App Routing in Proxy Managerenables per-app routing and sets one app's mode, after confirmation
Open Proxy Manageropens the dashboard, Settings, Targets or Apps

Suggested phrases

  • “Toggle Proxy Manager routing”
  • “Check Proxy Manager status”
  • “Add a Proxy Manager target”
  • “Open Proxy Manager”

Everything else is in the Shortcuts gallery under Proxy Manager.

How it behaves

  • The intents run inside the app and call the same router as the other adapters, so validation, rate limits and the audit log apply unchanged.
  • Policy changes ask for confirmation. On macOS 15 and later the prompt names the change; on macOS 14 it is the system's generic confirmation.
  • If external control is off, the intent returns a dialog pointing at Settings → Integration instead of failing silently.
  • Set Set App Routing to the bundle identifier (for example com.example.app); it also turns per-app routing on.

Add one

  1. Open Shortcuts and create a shortcut.
  2. Search for “Proxy Manager” and pick an action.
  3. Fill in the host or bundle identifier if the action needs one.

Spotlight and Siri find the suggested phrases once the app has been opened at least once.
